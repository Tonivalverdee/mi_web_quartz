# Inmersión en FCX

### Descripción del curso
En esta inmersión de laboratorio de dos días, tendrá el desafío de configurar una variedad de productos Fortinet en función de un conjunto de objetivos. Los productos Fortinet en el laboratorio incluyen FortiGate, FortiManager, FortiAnalyzer, FortiWeb, FortiMail, FortiADC, FortiAuthenticator y FortiSandbox.

Durante las sesiones, un instructor certificado en ciberseguridad de FCX está disponible para responder preguntar y brindarle apoyo mientras completa las tareas.

### Quién debería asistir
Deberían asistir profesionales de redes y seguridad en busca de certificación FCX Cybersecurity.

### Prerrequisitos
Los requisitos para realizar este curso son: 
1. Portátil (pantalla de mínimo 15").
2. Conexión a internet que permite el acceso saliente al puerto 443/TCP.
3. Un navegador moderno compatible con HTML5.

### Objetivos
Después de completar el curso, comprenderá mejor el nivel y la complejidad de las tareas y la topología involucradas en el examen práctico NSE8. Esto le ayudará a prepararse para el examen práctico NSE8, donde se enfrentará a un conjunto diferente de tareas y una nueva topología del mismo nivel de complejidad.

### Requisitos del sistema
Para tomar el formato en línea de esta clase, debes utilizar una computadora que tenga lo siguiente:

- Una conexión a internet de alta velocidad
- Un navegador web actualizado
- Un visor de PDF
- Altavoces o auriculares
- Uno de los siguientes:
	- Soporte HTML 5
	- Un entorno de ejecución Java (JRE) actualizado con el complemento Java habilitado en su navegador web
Debes utilizar la conexión Ethernet por cable, no una conexión WiFi. Los firewalls, incluidos Windows Firewall o FortiClient, deben permitir conexiones a los laboratorios en línea.
