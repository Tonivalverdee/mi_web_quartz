# Administrador de seguridad de Azure Cloud

### Descripción del curso
En este curso, aprenderá sobre los diferentes componentes que componen la infraestructura de Microsoft Azure y los desafíos de seguridad que presentan estos entornos, incluyendo alta disponibilidad (HA), escalado automático, Azure Virtual WAN y conectores de redes definidas por software (SDN), y cómo administrar el tráfico en la nube con productos Fortinet.

### Quién debería asistir
Cualquier persona que sea responsable de la implementación o la gestión diaria de las soluciones Fortinet en Azure debe asistir a este curso.

### Prerrequisitos
Conocimiento general de los proveedores de IaaS y experiencia con las máquinas virtuales FortiGate y FortiWeb

### Requisitos previos de Azure
Para ejecutar los laboratorios en Azure, los estudiantes deben tener sus propias cuentas de Azure con lo siguiente:

- Una suscripción de pago por uso con un método de pago válido —la prueba gratuita no funcionará para algunos laboratorios
- La capacidad de implementar FortiGate y FortiWeb PAYG desde Azure Marketplace.
- Capacidad para al menos 10 vCPU en una sola región.
- Permisos para crear lo siguiente:

- Registros de aplicaciones (principal del servicio) y claves
- Equilibradores de carga
- VNets
- Máquinas virtuales con cuatro vCPU
- Hasta dos redes virtuales
- FortiGate VM como una sola VM, en HA y como unidad de escala

- La capacidad de hacer lo siguiente:

- Lea las propiedades de Active Directory y utilice las funciones de Azure

El costo estimado por estudiante para administrar el laboratorio, si se realiza dentro de los tiempos de laboratorio especificados y todo se elimina al final, es de USD $25 por día.

### Objetivos
Después de completar este curso, deberías poder:

- Implemente una máquina virtual FortiGate en Azure en modo único y HA
- Utilice plantillas de Fortinet para implementar fácilmente entornos complejos
- Implementar FortiWeb en Azure
- Utilice conectores SDN con Azure
- Integre máquinas virtuales FortiGate con Azure Virtual WAN
- Integre otros servicios y productos de Fortinet con Azure
