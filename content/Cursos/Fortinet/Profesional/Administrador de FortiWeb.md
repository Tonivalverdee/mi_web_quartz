# Administrador de FortiWeb

### Descripción del curso
En este curso, aprenderá cómo implementar, configurar y solucionar problemas de FortiWeb. Aprenderá conceptos clave de seguridad de aplicaciones web y explorará funciones de protección y rendimiento. Experimentarás simulaciones de tráfico y ataques que utilizan aplicaciones web reales. Aprenderá cómo distribuir la carga de servidores virtuales a servidores reales, al mismo tiempo que aplica parámetros lógicos, inspecciona el flujo y protege las cookies de sesión HTTP. También aprenderá cómo entrenar y configurar el aprendizaje automático, y cómo configurar la protección de API y la mitigación de bots.

### Quién debería asistir
Los profesionales de seguridad involucrados en la gestión, configuración, administración y monitoreo de FortiWeb en implementaciones de pequeñas y grandes empresas deben asistir a este curso.

### Prerrequisitos
Debes tener una comprensión de los temas tratados en _FCP - Administrador de FortiGate_, o tener experiencia equivalente.

También se recomienda que comprenda los siguientes temas:

- Protocolo HTTP
- Conocimientos básicos de HTML, JavaScript y lenguajes de páginas dinámicas del lado del servidor, como PHP

### Objetivos
Después de completar este curso, podrás:

- Defina el firewall de aplicaciones web y describa su función en la red
- Realizar configuración básica e implementación inicial
- Configurar FortiWeb para su implementación en un entorno de red con equilibrio de carga
- Implementar capacidades de aprendizaje automático de FortiWeb
- Configurar y personalizar firmas FortiWeb
- Configure FortiWeb para protegerse contra ataques DoS y desfiguración
- Configurar la protección de API y la mitigación de bots
- Implementar cifrado SSL/TLS, incluida la inspección y descarga
- Configurar funciones de autenticación de usuarios y control de acceso
- Configure FortiWeb para garantizar el cumplimiento de PCI DSS de sus aplicaciones web
- Configurar FortiWeb para realizar tareas de almacenamiento en caché y compresión
- Configure FortiWeb para realizar enrutamiento, reescritura y redirección basados en contenido HTTP
- Realice la resolución básica de problemas de FortiWeb

### Requisitos del sistema
Si tomas el formato online de esta clase, deberás utilizar una computadora que tenga lo siguiente:

- Conexión a Internet de alta velocidad
- Navegador web actualizado
- Visor de PDF
- Altavoces o auriculares
- Uno de los siguientes:

- Soporte HTML 5 **o**
- Entorno de ejecución de Java (JRE) actualizado con el complemento Java habilitado en su navegador web

Debes utilizar una conexión Ethernet por cable, _no_ una conexión Wi-Fi. Los firewalls, incluidos Windows Firewall o FortiClient, deben permitir conexiones a los laboratorios en línea.
