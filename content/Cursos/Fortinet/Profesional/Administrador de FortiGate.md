# Administrador de FortiGate

### Descripción del curso
En este curso, aprenderá a utilizar las funciones más comunes de FortiGate.

En laboratorios interactivos, explorará políticas de firewall, autenticación de usuarios, alta disponibilidad, SSL VPN, IPsec VPN de sitio a sitio, Fortinet Security Fabric y cómo proteger su red mediante perfiles de seguridad, como IPS, antivirus, filtrado web, control de aplicaciones y más. Estos fundamentos de administración le proporcionarán una comprensión sólida de cómo implementar las funciones más comunes de FortiGate.

### Quién debería asistir
Los profesionales de redes y seguridad involucrados en la gestión, configuración, administración y monitoreo de los dispositivos FortiGate utilizados para proteger las redes de sus organizaciones deben asistir a este curso.

Debe tener un conocimiento profundo de todos los temas tratados en el curso de Operador de FortiGate antes de asistir al curso de Administrador de FortiGate.

### Prerrequisitos
- Conocimiento de protocolos de red
- Comprensión básica de los conceptos de firewall

### Objetivos
Después de completar este curso, podrás:

- Configure la red básica de FortiGate desde la configuración predeterminada de fábrica
- Configurar y controlar el acceso del administrador a FortiGate
- Utilice la GUI y la CLI para la administración
- Controle el acceso a la red a las redes configuradas mediante políticas de firewall
- Aplicar reenvío de puertos, NAT de origen y NAT de destino
- Analizar una tabla de rutas de FortiGate
- Paquetes de ruta que utilizan rutas estáticas y basadas en políticas para implementaciones multiruta y con equilibrio de carga
- Configurar enrutamiento estático
- Paquetes de ruta que utilizan rutas estáticas para implementaciones multiruta y con equilibrio de carga
- Autenticar usuarios mediante LDAP y RADIUS
- Supervise a los usuarios del firewall desde la GUI de FortiGate
- Ofrezca acceso Fortinet Single Sign-On (FSSO) a los servicios de red, integrados con Microsoft Active Directory (AD)
- Comprender las funciones de cifrado y los certificados
- Inspeccione el tráfico protegido con SSL/TLS para evitar el cifrado utilizado para eludir las políticas de seguridad
- Configurar perfiles de seguridad para neutralizar amenazas y usos indebidos, incluidos virus, torrents y sitios web inapropiados
- Aplicar técnicas de control de aplicaciones para monitorear y controlar aplicaciones de red que puedan utilizar protocolos y puertos estándar o no estándar
- Ofrezca una VPN SSL para acceso seguro a su red privada
- Establecer un túnel VPN IPsec entre dos dispositivos FortiGate
- Configurar SD-WAN y verificar la distribución del tráfico
- Identificar las características del tejido de seguridad Fortinet
- Implemente dispositivos FortiGate como un clúster HA para lograr tolerancia a fallas y alto rendimiento
- Diagnosticar y corregir problemas comunes

### Requisitos del sistema
Si tomas el formato online de esta clase, deberás utilizar un ordenador que tenga lo siguiente:

- Una conexión a Internet de alta velocidad
- Un navegador web actualizado
- Un visor de PDF
- Altavoces o auriculares
- Uno de los siguientes:
    - Soporte HTML 5
    - Un entorno de ejecución de Java (JRE) actualizado con el complemento Java habilitado en su navegador web

Debes utilizar una conexión Ethernet por cable, _no_ una conexión Wi-Fi. Los firewalls, incluidos Windows Firewall o FortiClient, deben permitir conexiones a los laboratorios en línea.
