# Analista de FortiSIEM

### Descripción del curso
En este curso, aprenderá cómo utilizar FortiSIEM para buscar, enriquecer y analizar eventos de clientes en una organización de proveedores de servicios de seguridad administrados (MSSP). Aprenderá a realizar búsquedas históricas y en tiempo real y a crear consultas avanzadas. También aprenderá cómo realizar análisis y remediación de incidentes de seguridad.

### Quién debería asistir
Los profesionales de seguridad responsables de la detección, análisis y remediación de incidentes de seguridad utilizando FortiSIEM deben asistir a este curso.

### Prerrequisitos
Debes comprender los temas tratados en los siguientes cursos o tener experiencia equivalente:

- _FCF - Fundamentos de FortiGate_
- _Administrador de FortiSIEM_

### Objetivos
Después de completar este curso, deberías poder:

- Identificar los impulsores comerciales para el uso de herramientas SIEM
- Describa cómo FortiSIEM resuelve desafíos comunes de ciberseguridad
- Describa los componentes principales y la arquitectura de base de datos única en FortiSIEM
- Realizar búsquedas históricas y en tiempo real
- Definir operadores de búsqueda estructurados y condiciones de búsqueda
- Hacer referencia a los datos del CMDB en búsquedas estructuradas
- Agregar campos y columnas de visualización
- Cree consultas a partir de resultados de búsqueda y eventos
- Cree consultas anidadas y tablas de búsqueda
- Construir subpatrones y condiciones de reglas
- Identificar interfaces y procesos críticos
- Crea reglas usando líneas de base
- Analizar un informe de perfil
- Analizar anomalías frente a líneas de base
- Analice las diferentes vistas del panel de incidentes
- Refinar y afinar incidentes
- Limpiar un incidente
- Exportar un informe de incidente
- Cree condiciones claras basadas en el tiempo y en patrones
- Configurar políticas de automatización
- Configurar scripts y acciones de remediación
- Diferenciar entre remediación manual y automática
- Configurar notificaciones

### Requisitos del sistema
Si tomas el formato online de esta clase, deberás utilizar un ordenador que tenga lo siguiente:

- Una conexión a Internet de alta velocidad
- Un navegador web actualizado
- Un visor de PDF
- Altavoces o auriculares
- Uno de los siguientes:

- Soporte HTML 5
- Un entorno de ejecución de Java (JRE) actualizado con el complemento Java habilitado en su navegador web

Debes utilizar una conexión Ethernet por cable, _no_ una conexión WiFi. Los firewalls, incluidos Windows Firewall o FortiClient, deben permitir conexiones a los laboratorios en línea.
