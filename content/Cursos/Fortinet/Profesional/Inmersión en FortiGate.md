# Inmersión en FortiGate

### Descripción del curso
En este curso exclusivo de laboratorio, disponible únicamente para compra, se le asigna una serie de tareas de configuración que puede realizar usted mismo (DIY) en un entorno de laboratorio virtual.

Las tareas de configuración cubren algunos de los temas del _FCP - Administrador de FortiGate 7.6_ examen de certificación e incluye el uso de las funciones más comunes de FortiGate, como políticas de firewall, Fortinet Security Fabric, autenticación de usuario, VPN SSL e IPsec, enrutamiento multiruta de igual costo (ECMP), IPS, alta disponibilidad (HA) e inspección de contenido.

### Quién debería asistir
Los profesionales de redes y seguridad involucrados en la gestión, configuración, administración y monitoreo de los dispositivos FortiGate utilizados para proteger las redes de sus organizaciones deben asistir a este curso.

Este curso es ideal para estudiantes que ya han realizado el FCP - _Administrador de FortiGate_ curso, o tener experiencia laboral equivalente y querer obtener más experiencia práctica en laboratorio antes de tomar el FCP - _Administrador de FortiGate 7.6_ examen de certificación.

### Prerrequisitos
Debe comprender los temas tratados en el FCP: _Administrador de FortiGate_ curso (o tener experiencia equivalente).

### Objetivos
Después de completar este curso, deberías poder:

- Utilice la GUI y la CLI para la administración
- Controlar el acceso a los recursos de la red mediante políticas de firewall
- Autenticar usuarios mediante políticas de firewall
- Inspeccione el tráfico protegido con SSL/TLS para evitar el cifrado utilizado para eludir las políticas de seguridad
- Aplicar filtros web y técnicas de control de aplicaciones para monitorear y controlar aplicaciones de red que puedan usar protocolos y puertos estándar o no estándar
- Proteja su red contra ataques conocidos utilizando firmas IPS
- Configure SSL VPN e IPSec VPN para acceso remoto
- Enrutar paquetes mediante enrutamiento ECMP
- Implemente dispositivos FortiGate como un clúster HA para lograr tolerancia a fallas y alto rendimiento
- Configurar la estructura de seguridad de Fortinet
- Configurar la estructura de seguridad de Fortinet

### Requisitos del sistema
Si tomas el formato online de esta clase, deberás utilizar un ordenador que tenga lo siguiente:

- Una conexión a Internet de alta velocidad
- Un navegador web actualizado
- Un visor de PDF
- Altavoces o auriculares
- Uno de los siguientes:
    - Soporte HTML 5
    - Un entorno de ejecución de Java (JRE) actualizado con el complemento Java habilitado en su navegador web

Debes utilizar una conexión Ethernet por cable, _no_ una conexión WiFi. Los firewalls, incluidos Windows Firewall o FortiClient, deben permitir conexiones a los laboratorios en línea.
