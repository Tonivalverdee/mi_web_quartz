# Administrador de FortiManager

### Descripción del curso
En este curso, aprenderá los fundamentos del uso de FortiManager para la administración centralizada de la red de muchos dispositivos FortiGate.

En los laboratorios interactivos, explorará estrategias de implementación, que incluyen ADOM únicos o múltiples, registro de dispositivos, paquetes de políticas, objetos compartidos, instalación de cambios de configuración, aprovisionamiento de FortiManager como un servidor de distribución local de FortiGuard y resolución de problemas de las funciones que son críticas para el uso diario después de implementar FortiManager.

### Quién debería asistir
Cualquier persona que sea responsable de la gestión diaria de las políticas de seguridad de FortiGate utilizando la plataforma FortiManager debe asistir a este curso.

### Prerrequisitos
- Conocimiento de conceptos de firewall en una red IPv4
- Familiaridad con todos los temas del _FCP - Administrador de FortiGate_ curso.
- Comprensión básica de los sistemas de gestión de redes

### Objetivos
Después de completar este curso, podrás:

- Describa las características y conceptos clave de FortiManager
- Cree ADOM para admitir varios clientes en un solo FortiManager
- Modifique el acceso simultáneo a ADOM mediante el uso de modos de espacio de trabajo
- Utilice plantillas de aprovisionamiento para cambios a nivel de dispositivo en muchos dispositivos
- Identifique los estados de sincronización y administre el historial de revisiones de los dispositivos administrados
- Administre políticas de firewall en múltiples dispositivos FortiGate utilizando paquetes de políticas con objetos compartidos y dinámicos
- Transferir políticas y objetos desde el ADOM global a múltiples ADOM
- Explique la estructura de seguridad de Fortinet con FortiManager
- Describa opciones de alta disponibilidad (HA), copia de seguridad y recuperación para FortiManager
- Administre el firmware de los dispositivos compatibles de forma centralizada
- Implemente un servidor de distribución FortiGuard (FDS) local para sus dispositivos Fortinet
- Diagnosticar y solucionar problemas de importación e instalación

### Requisitos del sistema
Si tomas el formato online de esta clase, deberás utilizar un ordenador que tenga lo siguiente:

- Una conexión a Internet de alta velocidad
- Un navegador web actualizado
- Un visor de PDF
- Altavoces o auriculares

- Soporte HTML 5
