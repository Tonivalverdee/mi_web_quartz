# Administrador de FortiAnalyzer

### Descripción del curso
En este curso, aprenderá cómo implementar, configurar y proteger FortiAnalyzer. También aprenderá cómo registrar y administrar dispositivos, configurar y administrar alta disponibilidad y administrar cuotas de disco. Por último, explorará los fundamentos de las capacidades de gestión de registros e informes incluidas en FortiAnalyzer.

### Quién debería asistir
Los profesionales de seguridad involucrados en la implementación, administración, mantenimiento y resolución de problemas de los dispositivos FortiAnalyzer deben asistir a este curso.

### Prerrequisitos
Debes estar familiarizado y comprender todos los temas tratados en el _FCA - Operador de FortiGate_ curso, o tener experiencia equivalente.

### Objetivos
Después de completar este curso, podrás:

- Describe el propósito de FortiAnalyzer
- Describa los modos de funcionamiento de FortiAnalyzer
- Describa el registro en un entorno Fortinet Security Fabric
- Describe la tela FortiAnalyzer
- Describa el flujo de trabajo del archivo de registro
- Gestionar dominios administrativos (ADOM)
- Configurar ajustes de red
- Configurar acceso administrativo seguro
- Configurar la autenticación de dos factores
- Monitorear eventos administrativos
- Registrar y administrar dispositivos
- Realizar una copia de seguridad de la configuración del sistema
- Supervisar el uso del disco
- Habilitar y crear ADOM
- Describir conectores de tela
- Configurar la redundancia de registros y el cifrado
- Configurar políticas de renovación y retención de registros
- Gestionar informes
- Prepare la actualización del firmware
- Configurar y administrar clústeres de alta disponibilidad
- Realizar tareas de mantenimiento del sistema
- Realizar copias de seguridad de registros

### Requisitos del sistema
Si tomas el formato online de esta clase, deberás utilizar un ordenador que tenga lo siguiente:

- Una conexión a Internet de alta velocidad
- Un navegador web actualizado
- Un visor de PDF
- Altavoces o auriculares
- Uno de los siguientes:

- Soporte HTML 5
- Un entorno de ejecución de Java (JRE) actualizado con el complemento Java habilitado en su navegador web

Debes utilizar una conexión Ethernet por cable, _no_ una conexión Wi-Fi. Los firewalls, incluidos Windows Firewall o FortiClient, deben permitir conexiones a los laboratorios en línea.
