# Analista de FortiAnalyzer

### Descripción del curso
En este curso, adquirirá las habilidades prácticas de un analista de SOC que utiliza FortiAnalyzer para el registro y análisis centralizados. Aprenderá cómo examinar y administrar eventos y automatizar la respuesta a amenazas utilizando controladores de eventos y manuales. También aprenderá cómo identificar amenazas actuales y potenciales a través de análisis de incidentes e informes de brotes. Finalmente, aprenderá cómo incorporar FortiAI en su flujo de trabajo y generar informes de seguridad.

### Quién debería asistir
Los profesionales de seguridad responsables del análisis de Fortinet Security Fabric y de la automatización de tareas para detectar y responder a ciberataques utilizando FortiAnalyzer deben asistir a este curso.

### Prerrequisitos
Debes comprender los temas tratados en los siguientes cursos o tener experiencia equivalente:

- FCA - _Operador de FortiGate_
- _Administrador de FortiAnalyzer_

También se recomienda tener conocimientos del siguiente tema:

- SQL SELECCIONAR sintaxis de la declaración

### Requisitos del sistema
Si tomas el formato online de esta clase, deberás utilizar un ordenador que tenga lo siguiente:

- Una conexión a Internet de alta velocidad
- Un navegador web actualizado
- Un visor de PDF
- Altavoces o auriculares
- Uno de los siguientes:

- Soporte HTML 5
- Un entorno de ejecución de Java (JRE) actualizado con el complemento Java habilitado en su navegador web
