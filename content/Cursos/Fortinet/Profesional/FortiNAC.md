# FortiNAC

### Descripción del curso
En este curso, aprenderá cómo aprovechar las poderosas y diversas capacidades de FortiNAC, utilizando las mejores prácticas para lograr visibilidad, control y respuesta. Estos fundamentos le proporcionarán una comprensión sólida de cómo implementar la visibilidad de la red y la automatización de la seguridad.

### Quién debería asistir
Los administradores de redes y seguridad, gerentes y otro personal de TI que utilizarán FortiNAC deben asistir a este curso.

### Prerrequisitos
Se recomienda que comprenda los siguientes temas:

- Conceptos y términos de networking
- Protocolos de red
- Configuraciones de infraestructura

### Objetivos
Después de completar este curso, deberías poder:

- Configure un sistema FortiNAC para lograr visibilidad de la red
- Aproveche las capacidades de control para el acceso a la red y la aplicación automatizada de políticas
- Integre FortiNAC en Fortinet Security Fabric
- Combine las funciones de visibilidad y control con integraciones de dispositivos de seguridad para automatizar las respuestas a amenazas a los riesgos de seguridad

### Requisitos del sistema
Si tomas el formato online de esta clase, deberás utilizar un ordenador que tenga lo siguiente:

- Una conexión a Internet de alta velocidad
- Un navegador web actualizado
- Un visor de PDF
- Altavoces o auriculares
- Uno de los siguientes:
    - Soporte HTML 5
    - Un entorno de ejecución de Java (JRE) actualizado con el complemento Java habilitado en su navegador web

Debes utilizar una conexión Ethernet por cable, _no_ una conexión Wi-Fi. Los firewalls, incluidos Windows Firewall o FortiClient, deben permitir conexiones a los laboratorios en línea.
