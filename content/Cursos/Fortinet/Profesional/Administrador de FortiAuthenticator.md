# Administrador de FortiAuthenticator

### Descripción del curso
En este curso, aprenderá cómo utilizar FortiAuthenticator para la autenticación segura y la gestión de identidad. Aprenderá cómo configurar e implementar FortiAuthenticator, utilizar FortiAuthenticator para la gestión de certificados y la autenticación de dos factores, autenticar usuarios utilizando servidores LDAP y RADIUS y explorar las opciones SAML SSO en FortiAuthenticator.

### Quién debería asistir
Cualquier persona que sea responsable de la gestión diaria de FortiAuthenticator debe asistir a este curso.

### Prerrequisitos
Debes tener una comprensión de los temas tratados en _FCP - Seguridad de FortiGate_ y _FCP - Infraestructura FortiGate_ , o tener experiencia equivalente.

También se recomienda que tenga conocimientos de autenticación, autorización y contabilidad (AAA).

### Objetivos
Después de completar este curso, podrás:

- Implementar y configurar FortiAuthenticator
- Configurar los servicios LDAP y RADIUS
- Configurar el portal de autoservicio
- Configure FortiAuthenticator y FortiGate para la autenticación de dos factores
- Provisión de tokens de hardware y software móvil FortiToken
- Configure FortiAuthenticator como un recopilador de eventos de inicio de sesión utilizando el marco de comunicación FSSO
- Configurar servicios de portal para la gestión de huéspedes y usuarios locales
- Configure FortiAuthenticator para autenticación 802.1x cableada e inalámbrica, autenticación basada en MAC y autenticación basada en máquina utilizando métodos EAP compatibles
- Solucionar problemas de autenticación
- Administrar certificados digitales (certificados digitales de CA raíz, sub-CA, usuario y servicios locales)
- Configure FortiAuthenticator como servidor SCEP para CRL y CSR
- Configure FortiAuthenticator para proporcionar servicios OAuth
- Configure FortiAuthenticator como proveedor de identidad SAML y proveedor de servicios
- Supervisar y solucionar problemas SAML
- Configurar FIDO para autenticación sin contraseña

### Requisitos del sistema
Si tomas el formato online de esta clase, deberás utilizar un ordenador que tenga lo siguiente:

- Una conexión a Internet de alta velocidad
- Un navegador web actualizado
- Un visor de PDF
