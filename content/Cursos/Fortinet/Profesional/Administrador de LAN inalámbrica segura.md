# Administrador de LAN inalámbrica segura

### Descripción del curso
En este curso, aprenderá cómo implementar, configurar y solucionar problemas de LAN inalámbrica segura utilizando una solución inalámbrica integrada. Mediante laboratorios interactivos, reforzará sus conocimientos sobre cómo implementar una LAN inalámbrica segura administrada de forma centralizada desde el controlador inalámbrico FortiGate.

### Quién debería asistir
Este curso está dirigido a profesionales de redes y seguridad involucrados en la gestión, configuración, administración y monitoreo de la solución integrada y/o inalámbrica en la nube de Fortinet.

### Prerrequisitos
- Comprensión de las redes inalámbricas básicas

- Revisar el suplemento _Fundamentos de la red inalámbrica_ lección

- Comprensión de los temas tratados en el _FCP - Administrador de FortiGate_ curso
- Comprensión de los temas tratados en el _FCP - Administrador de FortiAuthenticator_ También se recomienda el curso.

### Objetivos
Después de completar este curso, podrás:

- Comprenda el controlador inalámbrico
- Provisión de FortiAP en FortiLAN Cloud
- Conozca los diferentes modos de tráfico de SSID
- Implemente múltiples SSID inalámbricos
- Ofrezca acceso inalámbrico seguro con autenticación 802.1X
- Implemente redes inalámbricas con WPA3
- Implementar redes inalámbricas con VLAN
- Comprenda el NAC inalámbrico integrado FortiOS
- Thwart hackers de puntos de acceso y AP fraudulentos
- Explore los servicios de ubicación de FortiPresence
- Comprenda el equilibrio rápido de carga de clientes inalámbricos y de roaming
- Explora la API REST de FortiAP
- Solucionar problemas de LAN inalámbrica
- Explora la solución FortiAIOps

### Requisitos del sistema
Si tomas el formato online de esta clase, deberás utilizar un ordenador que tenga lo siguiente:

- Una conexión a Internet de alta velocidad
- Un navegador web actualizado
- Un visor de PDF
- Altavoces o auriculares
- Soporte HTML 5

Debes utilizar una conexión Ethernet por cable, _no_ una conexión WiFi. Los firewalls, incluidos Windows Firewall o FortiClient, deben permitir conexiones a los laboratorios en línea.
