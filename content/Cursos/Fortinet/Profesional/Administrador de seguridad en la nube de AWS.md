# Administrador de seguridad en la nube de AWS

### Descripción del curso
En este curso, aprenderá sobre los diferentes componentes que componen la infraestructura de Amazon Web Services (AWS) y los desafíos de seguridad que presentan estos entornos, incluida la alta disponibilidad (HA), el equilibrio de carga y los conectores de redes definidas por software (SDN), y cómo administrar el tráfico en la nube con productos Fortinet.

### Quién debería asistir
Cualquier persona que sea responsable de la implementación o la gestión diaria de las soluciones Fortinet en AWS debe asistir a este curso.

### Prerrequisitos
Conocimiento general de los proveedores de IaaS y experiencia con máquinas virtuales FortiGate.

### Requisitos previos de AWS
No se requieren requisitos previos. Las cuentas de AWS se proporcionan al inicio del curso.

### Objetivos
Después de completar este curso, deberías poder:

- Comprender el concepto de nube pública
- Conozca los distintos términos del servicio de nube pública de AWS
- Identificar amenazas y desafíos en la nube pública
- Asegure la nube de AWS
- Comprenda varias implementaciones de nube pública
- Describa los modelos de licencia de Fortinet
- Familiarícese con Github
- Describa los componentes del servicio AWS
- Identificar los componentes principales de la red de AWS
- Identifique los componentes de seguridad de AWS
- Describa las limitaciones del firewall de red de AWS
- Comprender el flujo de tráfico en una red virtual
- Comprender el flujo de tráfico de la capa 2
- Comprender el enrutamiento y las restricciones
- Identifique los productos Fortinet en AWS Marketplace
- Comprenda las implementaciones de Fortinet en AWS
- Comprenda las ofertas de Fortinet para firewall de aplicaciones web (WAF) en AWS
- Describe FortiWeb Cloud
- Comprenda las diferentes arquitecturas HA en AWS
- Identificar HA activo-pasivo nativo de FortiGate
- Comprenda FortiGate HA activo-pasivo en dos AZ
- Familiarícese con AWS CloudFormation
- Identificar diferentes tipos de equilibradores de carga
- Comprenda FortiGate active-active HA con AWS ELB
- Comprender GWLB
- Comprenda FortiGate CNF
- Identificar las diferencias entre FortiGate CNF y FortiGate VM
