# FortiEDR

### Descripción del curso
En esta clase, aprenderá cómo usar FortiEDR para proteger sus puntos finales contra ataques avanzados con funcionalidad de respuesta a incidentes orquestada en tiempo real. También explorará las funciones de FortiEDR y cómo protegen sus puntos finales automáticamente en tiempo real.

### Quién debería asistir
Los profesionales de TI y seguridad involucrados en la administración y el apoyo de FortiEDR deben asistir a este curso.

### Prerrequisitos
- Una comprensión básica de los conceptos de ciberseguridad

### Objetivos
Después de completar este curso, deberías poder:

- Explique el enfoque FortiEDR y cómo funciona
- Identifique los componentes comunicantes y cómo están configurados
- Realizar tareas administrativas importantes, que incluyen: administrar usuarios de la consola, actualizar recopiladores, eliminar datos personales para cumplir con el RGPD, implementar un entorno multiinquilino y ver eventos del sistema
- Realice los pasos básicos de solución de problemas, que incluyen: verificar que FortiEDR esté instalado y bloquear activamente el malware, identificar si FortiEDR ha bloqueado un proceso o una conexión, encontrar registros y comunicarse con el soporte de FortiEDR
- Realizar tareas administrativas importantes, que incluyen: administrar usuarios de la consola, actualizar recopiladores, eliminar datos personales para cumplir con el RGPD y ver eventos del sistema
- Reconozca qué es Fortinet Cloud Service y cómo funciona
- Complete las tareas básicas en cada área de la consola de administración: el Panel de control, el Visor de eventos, la pestaña Forense, el módulo Caza de amenazas, Control de comunicación, Políticas de seguridad, Playbooks, Inventario y la pestaña Administración
- Gestionar eventos de seguridad y su estado
- Bloquear la comunicación desde aplicaciones que sean riesgosas o no deseadas, pero que no sean inherentemente maliciosas
- Encuentre y elimine ejecutables maliciosos de todos los dispositivos de su entorno
- Comprenda cómo FortiEDR se integra con Fortinet Security Fabric y cómo funciona FortiXDR
- Utilice la API RESTful para administrar su entorno FortiEDR
- Priorizar, investigar y analizar eventos de seguridad
- Remediar eventos maliciosos y crear excepciones para permitir procesos seguros
- Realice tareas básicas de resolución de problemas en todos los componentes de FortiEDR
- Obtener registros de recopiladores y volcados de memoria

### Requisitos del sistema
Si tomas una versión en línea de esta clase, debes tener una computadora con:

- Una conexión a Internet de alta velocidad
- Un navegador web actualizado
- Un visor de PDF
- Altavoces / auriculares
- Uno de los siguientes:

- Compatibilidad con HTML5
- Un entorno de ejecución de Java (JRE) actualizado con el complemento Java habilitado en su navegador web

Debes utilizar una conexión Ethernet por cable, _no_ una conexión WiFi. Los firewalls, incluidos Windows Firewall o FortiClient, deben permitir conexiones a los laboratorios en línea.
