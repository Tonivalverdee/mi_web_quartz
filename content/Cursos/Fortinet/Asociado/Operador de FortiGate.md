# Operador de FortiGate

### Descripción del curso
En este curso, aprenderá cómo reforzar la seguridad de su red utilizando las funciones más comunes de FortiGate. A través de demostraciones y simulaciones interactivas, aprenderá cómo realizar tareas operativas básicas en FortiGate. Luego podrá aprovechar este conocimiento explorando temas más avanzados relacionados con estas características.

### Quién debería asistir
Los profesionales de TI y ciberseguridad que realizan operaciones diarias de red y necesitan realizar tareas administrativas básicas utilizando FortiGate deben asistir a este curso.

### Prerrequisitos
Se recomienda que comprenda los temas tratados en los siguientes cursos o tenga experiencia equivalente:

- _Fundamentos de la red_
- _Introducción al panorama de amenazas_
- _Introducción técnica a la ciberseguridad_

### Objetivos
Después de completar este curso, podrás:

- Configure las funciones más comunes y de alto nivel en los dispositivos FortiGate
- Conecte usuarios remotos a la red corporativa de forma segura mediante VPN
- Restringir el acceso a los recursos de la red
- Supervise los indicadores y registros esenciales en los dispositivos FortiGate
- Realizar mantenimiento básico del sistema

### Requisitos del sistema
Si tomas el formato online de esta clase, deberás utilizar un ordenador que tenga lo siguiente:

- Una conexión a Internet de alta velocidad
- Un navegador web actualizado
- Un visor de PDF
- Altavoces o auriculares
- Uno de los siguientes:
    - Soporte HTML 5
    - Un entorno de ejecución de Java (JRE) actualizado con el complemento Java habilitado en su navegador web

Debes utilizar una conexión Ethernet por cable, _no_ una conexión Wi-Fi. Los firewalls, incluidos Windows Firewall o FortiClient, deben permitir conexiones a los laboratorios en línea.
