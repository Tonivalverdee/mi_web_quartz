# Introducción al panorama de amenazas

### Descripción del curso
En este curso, aprenderá sobre el panorama de las ciberamenazas. Este panorama incluye las amenazas que ponen en peligro las redes informáticas, el elenco de malos actores que están detrás de estas amenazas y los primeros principios de ciberseguridad que, si se siguen, pueden mantenerlo a usted y a su red informática seguros. Este curso está diseñado como un punto de entrada para personas nuevas en ciberseguridad.

### Quién debería asistir
Cualquiera que quiera aprender sobre el panorama de amenazas debe asistir a este curso.

### Prerrequisitos
- No existen requisitos previos para este curso.

### Objetivos
Después de completar este curso, podrás:

- Describir la ciberseguridad y los principios de la seguridad de la información
- Identificar los tipos de malos actores, sus métodos y las contramedidas utilizadas contra ellos
- Enumere diferentes técnicas de ingeniería social
- Describa los tipos de malware y sus métodos de distribución

### Requisitos del sistema
Si tomas el formato online de esta clase, deberás utilizar un ordenador que tenga lo siguiente:

- Una conexión a Internet de alta velocidad
- Un navegador web actualizado
- Un visor de PDF
- Altavoces o auriculares
- Uno de los siguientes:
    - Soporte HTML 5
    - Un entorno de ejecución de Java (JRE) actualizado con el complemento Java habilitado en su navegador web

Debes utilizar una conexión Ethernet por cable, _no_ una conexión WiFi. Los firewalls, incluidos Windows Firewall o FortiClient, deben permitir conexiones a los laboratorios en línea.
