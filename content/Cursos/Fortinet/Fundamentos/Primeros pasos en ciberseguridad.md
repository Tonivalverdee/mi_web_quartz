# Primeros pasos en ciberseguridad

### Descripción del curso
En este curso aprenderás sobre los conceptos básicos de la ciberseguridad. Este curso está diseñado como un punto de entrada para cualquier persona interesada en aprender sobre ciberseguridad e introduce conceptos y tecnología básicos de ciberseguridad. Luego podrá aprovechar estos conceptos para explorar temas de ciberseguridad más detallados.

### Quién debería asistir
Este curso se recomienda a profesionales en ventas y roles no técnicos que quieran aprender sobre ciberseguridad y productos de seguridad. Si eres un profesional en un rol técnico o quieres obtener otras certificaciones Fortinet, te recomendamos [Introducción técnica a la ciberseguridad](https://training.fortinet.com/local/staticpage/view.php?page=library_technical-introduction-to-cybersecurity) en cambio.

### Prerrequisitos
- Se recomienda que completes el _FCF - Introducción al panorama de amenazas_ curso antes de comenzar este curso.

### Objetivos
Después de completar este curso, podrás:

- Identifique conceptos de seguridad de red y explique cómo protegen las redes y los datos
- Describa cómo se ha desarrollado la tecnología de seguridad de red para contrarrestar las ciberamenazas en evolución

### Requisitos del sistema
Si tomas el formato online de esta clase, deberás utilizar un ordenador que tenga lo siguiente:

- Una conexión a Internet de alta velocidad
- Un navegador web actualizado
- Un visor de PDF
- Altavoces o auriculares
- Uno de los siguientes:
    - Soporte HTML 5
    - Un entorno de ejecución de Java (JRE) actualizado con el complemento Java habilitado en su navegador web

Debes utilizar una conexión Ethernet por cable, _no_ una conexión WiFi. Los firewalls, incluidos Windows Firewall o FortiClient, deben permitir conexiones a los laboratorios en línea.
