# Ingeniero de soporte de seguridad de red

### Descripción del curso
En este curso, aprenderá cómo diagnosticar y solucionar los problemas de seguridad y redes más comunes en una solución de seguridad de red protegida de Fortinet. En laboratorios interactivos de reparación y reparación, utilizará herramientas, diagnósticos y comandos de depuración para detectar, aislar y resolver problemas relacionados con las funciones de FortiGate más utilizadas, como IPsec, enrutamiento, filtrado web, alta disponibilidad (HA), IPS y más. Estas habilidades y este conocimiento le brindarán una comprensión avanzada de cómo respaldar una solución de seguridad de red basada en dispositivos FortiGate.

### Quién debería asistir
Los profesionales de redes y seguridad involucrados en el diagnóstico, resolución de problemas y soporte de una infraestructura de seguridad empresarial utilizando dispositivos FortiGate deben asistir a este curso.

Este curso supone conocimientos avanzados de networking y una amplia experiencia práctica trabajando con FortiGate.

### Objetivos
Después de completar este curso, podrás:

- Establezca una línea base para FortiGate y analice los primeros pasos para diagnosticar un FortiGate
- Supervise la actividad del proceso, diagnostique el modo de conservación y solucione problemas de reinicios inesperados y dispositivos congelados
- Analice la información en la tabla de sesiones y depure la salida del flujo
- Solucionar problemas de los ayudantes de sesión
- Solucionar problemas comunes relacionados con la autenticación local, LDAP, RADIUS y SAML
- Solucionar problemas comunes de FSSO
- Solucionar problemas de FortiGuard y filtrado web
- Supervise un clúster de HA y solucione problemas comunes de HA
- Solucione problemas y diagnostique VPN IPsec con comandos de depuración y rastreo
- Solucione problemas de enrutamiento con comandos de depuración
- Supervise el estado de OSPF y solucione problemas comunes de OSPF con comandos de depuración
- Supervise y verifique el estado de BGP con comandos y solucione problemas comunes de BGP
