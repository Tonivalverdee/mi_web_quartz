# Arquitecto de seguridad de la nube pública

### Descripción del curso
En este curso, aprenderá cómo implementar soluciones Fortinet en la nube pública utilizando varios métodos. Aprenderá a utilizar herramientas de automatización de terceros para implementar y proteger sus recursos en la nube. También aprenderá cómo solucionar eficazmente problemas de conectividad comunes en Azure y AWS, y cómo usar FortiCNP para simplificar la gestión de riesgos para sus cargas de trabajo en la nube.

### Quién debería asistir
Cualquier persona que sea responsable de la implementación o la gestión diaria de las soluciones Fortinet en proveedores de nube debe asistir a este curso.

### Prerrequisitos
- Conocimiento general de los proveedores de IaaS
- Experiencia con máquinas virtuales FortiGate, FortiWeb y Linux
- Finalización de la _FCP - Seguridad en la nube para AWS_ y _FCP - Seguridad en la nube para Azure_ cursos o una comprensión clara de los componentes de la red y cómo implementar recursos en Azure y AWS

### Requisitos previos de AWS
Laboratorios: los estudiantes deben tener cuenta propia con:

- Un método de pago válido registrado en la cuenta*
- Capacidad para un mínimo de cuatro IP elásticas y 15 vCPU en una sola región
- Capacidad para implementar instancias FortiGate EC2 con un total combinado de 10 o más interfaces de red
- Capacidad para implementar instancias FortiWeb EC2
- Permisos para crear lo siguiente:  
    - Mínimo pf 6 VPC y 10 instancias EC2
    - Cubo S3
    - Concha de nube
    - Grupos de seguridad
    - Puertas de enlace de Internet y tránsito
    - Funciones lambda
    - Usuarios de IAM con permisos AWSMarketplaceFullAccess y AmazonEC2FullAccess

### Requisitos previos de Azure
Laboratorios: los estudiantes deben tener cuenta propia con:

- Suscripción de pago por uso con método de pago válido*
- Capacidad para implementar FortiGate desde Azure Marketplace usando Bicep o Terraform
- Capacidad para al menos 16 vCPU en una sola región
- Capacidad para implementar máquinas virtuales FortiGate con un total combinado de 10 o más interfaces de red
- Permisos para crear lo siguiente:
    - Registros de aplicaciones (principal del servicio) y claves
    - Mínimo 6 VNets
    - Mínimo 7 máquinas virtuales con un total combinado de 15 vCPU
- La capacidad de hacer lo siguiente:
    - Ejecute Cloud Shell con configuración de almacenamiento
    - Lea las propiedades de Active Directory y utilice las funciones de Azure
    - Cree un usuario de IAM con permisos de rol de colaborador, propietario y administrador de acceso de usuario

*El costo estimado del laboratorio/estudiante, siguiendo todas las instrucciones, es de USD $15/proveedor de la nube/día. La prueba gratuita no funcionará para algunos ejercicios.

### Objetivos
Después de completar este curso, podrás:

- Describa las mejores prácticas al trabajar con implementaciones en la nube
- Utilice herramientas de automatización para implementar recursos en la nube en AWS y Azure
- Implemente soluciones Fortinet para proteger las implementaciones de IaaS
- Implemente soluciones Fortinet para proteger las implementaciones de CaaS
- Solucionar problemas de implementación en la nube y conectividad de red
- Utilice FortiCNP para simplificar la gestión de riesgos
