# Análisis avanzado

### Descripción del curso
En este curso, aprenderá cómo utilizar FortiSIEM en un entorno multiinquilino. Aprenderá sobre las reglas y su arquitectura, cómo se generan los incidentes, cómo se realizan los cálculos de referencia, los diferentes métodos de remediación disponibles y cómo funcionan las consultas anidadas y las tablas de búsqueda para análisis avanzados utilizando FortiSIEM. También aprenderá cómo integrar FortiSOAR con FortiSIEM.

### Quién debería asistir
Los profesionales de seguridad involucrados en la gestión, configuración, administración y monitoreo de dispositivos FortiSIEM y FortiSOAR —en una implementación empresarial o de un proveedor de servicios— que se utilizan para monitorear y proteger las redes de las organizaciones de clientes deben asistir a este curso.

### Prerrequisitos
Debes comprender los temas tratados en los siguientes cursos o tener experiencia equivalente:

- FCP - Seguridad de FortiGate
- FCP - Infraestructura FortiGate
- FCP - FortiSIEM

También se recomienda que comprenda los siguientes temas o tenga experiencia equivalente:

- Programación en Python
- Lenguaje de plantillas Jinja2 para Python
- Sistemas Linux
- Tecnologías SOAR

### Objetivos
Después de completar este curso, deberías poder:

- Identificar varios requisitos de implementación para un implementador FortiSIEM multiinquilino
- Implemente FortiSIEM en un entorno híbrido con y sin colectores
- Diseñe soluciones multiinquilino con FortiSIEM
- Implementar recolectores en un entorno multiinquilino
- Gestionar la asignación de EPS y las restricciones en FortiSIEM
- Gestionar la utilización de recursos de un clúster FortiSIEM multiinquilino
- Mantener y solucionar problemas en una instalación de colector
- Implementar y administrar agentes de Windows y Linux
- Cree reglas evaluando eventos de seguridad
- Definir acciones para una regla de seguridad de patrón único
- Identifique múltiples reglas de seguridad de patrones y defina condiciones y acciones para ellas
- Diferenciar entre un informe estándar y uno de referencia
- Crea tus propios perfiles de referencia
- Implementar agentes UEBA de FortiSIEM
- Examinar las reglas UEBA basadas en registros
- Examine consultas anidadas para análisis avanzados
- Configurar tablas de búsqueda para análisis avanzados
- Configurar condiciones claras en FortiSIEM
- Analice algunos scripts de remediación listos para usar
- Configure varios métodos de remediación en FortiSIEM
- Integre FortiSOAR con FortiSIEM
- Remediar incidentes de FortiSOAR

### Requisitos del sistema
Si tomas el formato online de esta clase, deberás utilizar un ordenador que tenga lo siguiente:

- Una conexión a Internet de alta velocidad
- Un navegador web actualizado
- Un visor de PDF
- Altavoces o auriculares

- Soporte HTML 5
