# Administrador de firewall empresarial

### Descripción del curso
En este curso, aprenderá cómo implementar y administrar de forma centralizada una infraestructura de seguridad empresarial compuesta por múltiples dispositivos FortiGate.

### Quién debería asistir
Los profesionales de redes y seguridad involucrados en el diseño y administración de una infraestructura de seguridad empresarial utilizando dispositivos FortiGate deben asistir a este curso.

Debe tener un conocimiento avanzado de redes y una amplia experiencia práctica trabajando con FortiGate, FortiManager y FortiAnalyzer.

### Prerrequisitos
Debes tener una comprensión de los temas tratados en _FCP - Administrador de FortiGate_ (o tener experiencia equivalente).

También se recomienda que comprenda los temas tratados en los siguientes cursos o tenga experiencia equivalente:

- _FCP - Administrador de FortiManager_
- _FCP - Administrador de FortiAnalyzer_

### Objetivos
Después de completar este curso, podrás:

- Centralizar la gestión y seguimiento de eventos de seguridad de la red
- Implemente una solución de alta disponibilidad (HA) en FortiGate
- Combine OSPF y BGP para enrutar el tráfico empresarial
- Servicios empresariales de Harden
- Implemente simultáneamente túneles IPsec en varios sitios utilizando las plantillas IPsec de FortiManager
- Configure ADVPN para habilitar túneles VPN bajo demanda entre sitios
- Integre FortiManager, FortiAnalyzer y varios dispositivos utilizando Fortinet Security Fabric
- Optimice los recursos de FortiGate

### Requisitos del sistema
Si tomas el formato online de esta clase, deberás utilizar un ordenador que tenga lo siguiente:

- Una conexión a Internet de alta velocidad
- Un navegador web actualizado
- Un visor de PDF
- Altavoces o auriculares
- Soporte HTML 5

Debes utilizar una conexión Ethernet por cable, _no_ una conexión WiFi. Los firewalls, incluidos Windows Firewall o FortiClient, deben permitir conexiones a los laboratorios en línea.
