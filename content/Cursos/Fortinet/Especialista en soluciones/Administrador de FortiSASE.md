# Administrador de FortiSASE

### Descripción del curso
En este curso, aprenderá cómo utilizar las funciones de FortiSASE, incluidos tipos de políticas, perfiles de puntos finales y perfiles de seguridad. Explorará la implementación de FortiSASE, la autenticación de usuarios, los casos de uso y el monitoreo. También aprenderá cómo proteger su tráfico web y sus aplicaciones de software como servicio (SaaS) mediante la inspección de contenido, como antivirus, filtrado web, control de aplicaciones y registro.

### Quién debería asistir
Los profesionales de redes y seguridad involucrados en el diseño, administración y gestión de la implementación de redes basadas en FortiSASE deben asistir a este curso.

### Prerrequisitos
Debes comprender los temas tratados en los siguientes cursos o tener experiencia equivalente:

- _FCP - Administrador de FortiGate_
- _FCP - Administrador de FortiClient EMS_

### Objetivos
Después de completar este curso, podrás:

- Describe la arquitectura SASE
- Construir casos de implementación de FortiSASE
- Identificar los componentes del SASE
- Describe la solución Fortinet SASE
- Integre FortiSASE en una red híbrida
- Describe las diferentes soluciones FortiSASE
- Describa diferentes métodos de autenticación en FortiSASE
- Configure el acceso a la red de confianza cero (ZTNA) con FortiSASE
- Configurar grupos de perfiles de seguridad y componentes de seguridad
- Configurar diferentes tipos de políticas FortiSASE
- Implementar casos de uso compatibles con FortiSASE
- Configurar monitores FortiView
- Configurar y generar informes
- Configurar paneles de control

### Requisitos del sistema
Si tomas el formato online de esta clase, deberás utilizar un ordenador que tenga lo siguiente:

- Una conexión a Internet de alta velocidad
- Un navegador web actualizado
- Un visor de PDF
- Altavoces o auriculares
- Uno de los siguientes:

- Soporte HTML 5 **o**
- Un entorno de ejecución de Java (JRE) actualizado con el complemento Java habilitado en su navegador web

Debes utilizar una conexión Ethernet por cable, _no_ una conexión WiFi. Los firewalls, incluidos Windows Firewall o FortiClient, deben permitir conexiones a los laboratorios en línea.
