# OT Security

### Course Description
En este curso, aprenderá cómo proteger su infraestructura OT utilizando soluciones Fortinet. Aprenderá cómo diseñar, implementar, administrar y monitorear dispositivos FortiGate, FortiNAC, FortiAnalyzer y FortiSIEM para proteger las infraestructuras OT. Estas habilidades le proporcionarán una comprensión sólida de cómo diseñar, implementar y operar una solución de seguridad OT basada en productos Fortinet.

### Quién debería asistir
Los profesionales de redes y seguridad involucrados en el diseño, implementación y administración de una infraestructura OT utilizando dispositivos Fortinet deben asistir a este curso.

### Prerrequisitos
Debes comprender los temas tratados en los siguientes cursos o tener experiencia equivalente:

- _FCP - Seguridad de FortiGate_
- _FCP - Infraestructura FortiGate_

También se recomienda que comprenda los temas tratados en los siguientes cursos o tenga experiencia equivalente:

- _FCP - FortiSIEM_
- FCP - Analizador Forti

### Objetivos
Después de completar este curso, podrás:

- Comprender los fundamentos de una infraestructura OT
- Asegure una infraestructura OT utilizando el modelo Purdue
- Utilice FortiGate y FortiNAC para identificar y administrar dispositivos
- Implementar segmentación y microsegmentación en una red OT
- Autenticar usuarios
- Proteja el tráfico de su red OT utilizando FortiGate
- Utilice FortiAnalyzer para registrar e informar
- Utilice FortiSIEM para centralizar la información de seguridad y la gestión de eventos
- Genere análisis en tiempo real de eventos de seguridad utilizando FortiSIEM

### Requisitos del sistema
Si tomas el formato online de esta clase, deberás utilizar un ordenador que tenga lo siguiente:

- Una conexión a Internet de alta velocidad
- Un navegador web actualizado
- Un visor de PDF
- Altavoces o auriculares
- Uno de los siguientes:
    - Soporte HTML 5
    - Un entorno de ejecución de Java (JRE) actualizado con el complemento Java habilitado en su navegador web

Debes utilizar una conexión Ethernet por cable, _no_ una conexión Wi-Fi. Los firewalls, incluidos Windows Firewall o FortiClient, deben permitir conexiones a los laboratorios en línea.
