# Personalización de entorno en Linux

Duración: 3 horas
Clases: 14
Nivel: Intermedio

## Descripción

¿Quieres tener el mismo entorno de trabajo en Linux que usa S4vitar en sus vídeos?, entonces este es tu curso.

Personaliza tu sistema operativo al máximo para sacarle el mayor rendimiento y mejorar tu movilidad sobre este, todo ello a través de este fantástico curso de 3 horas donde serás guiado paso a paso desde cero con el objetivo de que una vez lo termines, puedas disponer de tu nuevo entorno personalizado listo para ser usado.

Este curso lo mantendremos siempre actualizado, de forma que, en caso de que algún paquete o algo que utilicemos quede obsoleto o dé errores en la instalación, las clases que entren en conflicto serán regrabadas y trataremos de ofrecer otra alternativa para procurar el menor número de problemas posibles.

Recomendamos que inspecciones el temario del curso para que tengas en todo momento claro las cosas que vamos a estar tocando.

**Importante**: Este curso no está adaptado para llevarse a cabo desde un sistema operativo Mac. Gran parte de las configuraciones y herramientas que se presentan son específicas para Linux y no serán aplicables en **MacOS**.
